Bài toán: Chuyển đổi quy trình tính toán lợi nhuận thủ công sang luồng dữ liệu tự động.

Công nghệ: Python (Pandas, SQLAlchemy, glob), MS SQL Server.

Logic Kinh doanh (Business Logic): Nhấn mạnh việc bạn đã tự xây dựng công thức tính Giá vốn gánh Tỷ lệ hao hụt (Loss Rate) và xử lý triệt để bài toán đối soát dữ liệu (Data Reconciliation) giữa Python và SQL.
